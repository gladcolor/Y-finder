## Agent decisions (change them if Huan disagrees)

- Flask + gunicorn (same stack as Research Architect on the server); vanilla JS front end (no Node on the workstation).
- Fit labels are computed by rules in `fit.py`, never by the model. Unverified picks are shown but do not count toward graph coverage.
- BM25 search with synonyms and sensor tokens instead of embeddings: zero cost, good enough (search tests pass); embeddings are the next step.
- GeoLibre is embedded by URL parameters (`data=`, `layout=compact`, `panels=collapsed`); its postMessage API is off on the public site.
- Conversation history lives in the browser (`localStorage` key `yf_conversations_v1`, 30 conversations, 2.5 MB cap, oldest dropped), not on the server: no accounts, nothing kept server-side beyond the 6-hour session. Each turn is stored as the event stream the UI received (text deltas merged, only the last graph/scope/recommendations kept), so reopening replays the same view.
- `POST /api/session/restore` rebuilds an expired session from what the browser shows (graph, scope, picks, layers, the OpenAI response id from the `done` event, and a recap of the last 4 turns). It never overwrites a live session; fit labels are recomputed by the rules, layers must be files in this server's store, and the response id must look like `resp_...`. The next message gets the Data-tab list once; the turn recap is used only when the response chain is missing or expired.
- "New conversation" no longer deletes the server session (the old one stays reopenable); deleting a conversation from the list does.
- GeoLibre gallery maps are display snapshots: cards say "Snapshot", the agent is told to cite the original source, and the map tool returns the styled original (`web.geolibre.app/?url=<project>`). Big layers are cut to the study area, time series keep one year (the scope's end year, else the latest), the rest becomes an even sample (`yfinder/vector.py`, shared with downloads). Vector-tile layers (signed, expiring URLs) open only in GeoLibre.
- Project files are fetched only from `assets.geolibre.app` by a slug from the catalog, never from a model- or browser-supplied URL. Downloads accept public https only; every redirect hop is re-checked (`allow_redirects=False`), size is capped while streaming, zips are read in memory with a 300 MB unpacked cap, and downloaded files are never served back (only the GeoJSON layers made from them).
- Web links that the agent picks from web search are opened once (no redirects followed); no such host, refused, broken TLS, 404 or 410 marks the pick unverified and the agent is told to replace it. Sites that block scripts (403, 429) count as working. Off in tests (`YFINDER_LINKCHECK=0`).
- The study area must cover the whole named place: when the geocoder finds only a smaller feature inside it (a lake inside a reserve), the agent widens the box (a containing district, or the extent from a web search) and lists the extent as assumed.
- Heavy point layers keep about 10 m precision and at most 16 attributes, then become an even sample; they are never rounded to 0.01 degree (that snapped LAPD arrests onto a visible lattice).
- Y-finder's browser runs as the service user with no sandbox escape needed (Playwright's default no-sandbox launch); every request the page makes is checked against private and local addresses; images, media and fonts are not loaded.
- Exploration findings are computed by code; the model only picks matching categories (validated against the real values) and writes the closing reading from the computed findings. Correlations are reported as rank correlations with their unit and join, never as tests of a causal link; a finding whose evidence is a stand-in or an indirect path says so.
- Exploration starts by itself when previews are ready (the browser's `yf_explore_auto`, on by default); Stop keeps the findings and does not restart until the data change (new picks or scope) or the user presses Explore again.
- A preview must show the variable the question asks for: when a card measures a factor only through a stand-in, the explorer says so, and adapters choose the measure from the pick's factors (ACS race shares versus income; CT ECO canopy, water or 1934 aerials). An empty or tracker file is never a preview.
- Portal samples are drawn evenly over the study years and labelled; counts over time come from the portal's own aggregate query, never from the sample.
- A recording is kept only after reading it: when a re-recording is worse (fewer Yale sources, a wider box than the question names), the earlier one stays. `--index-only` rebuilds `index.json` and the results table without recording. Never edit a recording's answer text; re-record instead (fit labels are rules and may be recomputed).
- The answer's first sentence is the data route, not the limits; limits follow in the bullets.
- Screen sizes: tested at 1920x950, 2560x1310, 3440x1300 and 3840x2030 CSS pixels by loading the app in a same-origin iframe of
  that size (the test Chrome runs on a 4K display at 156% scaling, so the window cannot take exact CSS sizes). From 2600x1100
  the panel and the floating map controls scale by `--ui` (1.2, or 1.4 from 3400x1600) with CSS zoom and the panel widens;
  the map and graph canvases are never zoomed (zoom on a canvas ancestor shifts pointer positions); the graph canvas grows
  taller instead. Fixed positions inside zoomed elements divide by `--ui`.
- A view of part of the study area is never a scope change (`view_bbox` on `search_stac_items`).
- The cost under an answer is an estimate at list prices (`config.PRICES`, November 2026, from OpenAI's published rates as reported by price trackers; set `YFINDER_PRICES` when they change). The server sends `cost_usd` in the `done` event; the browser computes it for older recordings from their usage.
- Feedback is a vote plus an optional one-line comment, the question's first 300 characters, the model, the demo id and a hashed address. Never the conversation. It is the seed of the evaluation set from real use (open item 3).
- The data guide is built in the browser from `state` (graph, scope, picks, previews, methods, next steps, explore findings and synthesis, citations) and opened in a new tab; nothing is sent to the server. Keep it in step with the Data and Insights tabs when their fields change.
- ACS previews choose the variable from the pick's factor labels first and its reason second, in the order race, children, older, income, population; a plain "population" factor maps the count (a denominator), everything else without a match maps income.
- Demo cases are recorded and replayed so interviews do not depend on live latency; `/api/demo/<id>/load` restores the end state (including the OpenAI response id) so the conversation continues live.

## Gotchas

- **Cloudflare caches .js and .css for 4 hours** whatever the origin says. The index route stamps `?v=<content hash>`
  on app.js, app.css and demo JSON, so every deploy is picked up. Keep that if you add static files.
- Codex CLI on this workstation cannot run its file tools (`codex-code-mode-host.exe` missing). For reviews, pipe the files
  in: `for f in yfinder/*.py static/app.js; do echo "== $f"; nl -ba $f; done | codex exec -s read-only "review ..."`.
- GeoLibre iframe: iframes do not stretch between `left` and `right`; the CSS sets an explicit width.
- Some sites answer a missing file with "200 OK" and a text body ("404 File Not Found"); download errors quote short replies like that.
- A layer from an ended session's download returns 404; reopening an old conversation shows a toast instead of the layer.
- Imagery previews: `map_stac_preview` adds same-week neighbor scenes until the study box is covered (NAIP quarter quads are small).

- `localStorage` on `app.researcharchitect.ai` is shared with Research Architect (same origin); keep Y-finder keys prefixed `yf_` and the history under its 2.5 MB budget.
- The Chrome connected to Claude Code on this workstation is on another computer, so it cannot open `127.0.0.1`. Test the UI on the deployed URL.
- Bash sandbox: SSH works; a local server started inside the sandbox is not visible outside it (use `dangerouslyDisableSandbox`).
- Never commit `OpenAI_key.txt` (git-ignored, also excluded by `deploy.sh`). Scan before pushing: `git grep -n "sk-"`.
- Public Overpass servers are slow at times; the app falls back to a mirror and caps the area at about 50 x 50 km.
- Cloudflare cuts responses that send nothing for 100 s; streaming keeps the chat alive, but a slow single tool call can still hit it.
- Some government sites block scripted URL checks (403); that does not mean the curated link is broken.
- Yale access facts on curated cards come from YCGS and Yale Library pages (checked Oct and Nov 2026). Confirm with YCGS before a real launch.
