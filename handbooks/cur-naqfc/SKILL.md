# Access handbook: NOAA National Air Quality Forecast (CMAQ) on AWS

## What it is

NOAA’s National Air Quality Forecast Capability provides model forecasts of ozone and PM2.5 from January 2020 onward. The grids cover the contiguous US at about 5 km, Alaska at 6 km, and Hawaii at 2.5 km; ozone and PM2.5 forecasts run twice daily, at 06:00 and 12:00 UTC. ([registry.opendata.aws](https://registry.opendata.aws/noaa-nws-naqfc-pds/))

## How to get access

The AWS bucket is open to everyone. No AWS account, API key, registration, or Yale license is needed. Use the bucket browser for archived files, or NOAA’s NOMADS GRIB Filter for a small recent geographic subset. ([registry.opendata.aws](https://registry.opendata.aws/noaa-nws-naqfc-pds/))

## Programmatic access

- **AWS base:** `https://noaa-nws-naqfc-pds.s3.amazonaws.com/`; bucket `s3://noaa-nws-naqfc-pds/`, region `us-east-1`. List files with `aws s3 ls --no-sign-request s3://noaa-nws-naqfc-pds/`. Browse the listed keys rather than guessing file paths. ([registry.opendata.aws](https://registry.opendata.aws/noaa-nws-naqfc-pds/))
- **Subsets:** The separate NOMADS daily AQM filter lets you choose a date, cycle, file, variable, level, and bounding box, then generate a download URL. It is not an AWS endpoint and may not retain the full AWS history. ([nomads.ncep.noaa.gov](https://nomads.ncep.noaa.gov/gribfilter.php?ds=aqm_daily))
- **Authentication:** None. No credential environment variable is needed. The example uses an environment variable only to hold the generated URL.
- **Format:** Forecast grids are GRIB2. The NOMADS filter returns a GRIB2 subset. ([vlab.noaa.gov](https://vlab.noaa.gov/documents/17693964/40480065/2%2BYoungsun_Jung_NAQFC_2024_NWS.pptx/84aca1c1-574d-4503-f19c-c2c27f7e7538?t=1729017890962&targetExtension=pdf))
- **Rate limits:** No numeric AWS bucket limit was confirmed. For NOMADS loops, NOAA asks for a 10-second pause between downloads. ([nomads.ncep.noaa.gov](https://nomads.ncep.noaa.gov/info.php?page=gribfilter))

## Python example

This downloads a small **New Haven-area daily ozone subset from NOMADS**, rather than directly from AWS. First open the daily AQM filter listed below, select an available date, cycle and file, choose an ozone variable and level, and check **make subregion**. Enter left −73, right −72, bottom 41, and top 42; use **Show URL**, then set `GRIB_FILTER_URL` to the generated URL.

```python
import os
from pathlib import Path
from urllib.parse import urlparse
from urllib.request import urlopen

url = os.environ["GRIB_FILTER_URL"]
parsed = urlparse(url)
if parsed.scheme != "https" or parsed.hostname != "nomads.ncep.noaa.gov":
    raise ValueError("Use the HTTPS URL generated by the NOMADS filter")

with urlopen(url, timeout=120) as response:
    data = response.read()

if not data.startswith(b"GRIB"):
    raise ValueError("Response is not GRIB data; check the filter selection")
Path("new_haven_ozone.grib2").write_bytes(data)
print(f"Saved {len(data)} bytes to new_haven_ozone.grib2")
```

## Pitfalls

- These are **forecasts**, not measurements. Check the initialization time, forecast hour, averaging period, and whether a field is bias-corrected. ([registry.opendata.aws](https://registry.opendata.aws/noaa-nws-naqfc-pds/))
- NOAA describes ozone in parts per billion and PM2.5 in micrograms per cubic meter. Check the units in the individual GRIB metadata before analysis. ([registry.opendata.aws](https://registry.opendata.aws/noaa-nws-naqfc-pds/))
- Grid spacing differs by region. Inspect the GRIB projection and coordinates before overlaying the data with other GIS layers. ([registry.opendata.aws](https://registry.opendata.aws/noaa-nws-naqfc-pds/))
- The operational model changed on May 14, 2024: current guidance uses UFS with CMAQ-based chemistry, rather than the earlier CMAQ configuration. Account for changes when comparing years. ([registry.opendata.aws](https://registry.opendata.aws/noaa-nws-naqfc-pds/))
- A missing file or empty filter result can mean the selected date, cycle, variable, or level is unavailable. Check the live listing and selections.
- NOAA requests attribution for unaltered data. Do not imply NOAA endorsement, or describe modified data as unaltered NOAA data. ([registry.opendata.aws](https://registry.opendata.aws/noaa-nws-naqfc-pds/))
